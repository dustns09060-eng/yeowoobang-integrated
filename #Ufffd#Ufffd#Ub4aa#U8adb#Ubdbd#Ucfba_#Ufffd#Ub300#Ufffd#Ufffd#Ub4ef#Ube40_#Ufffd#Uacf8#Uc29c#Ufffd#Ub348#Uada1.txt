폭스바겐 내부 통합 수정본

변경사항
- 폭스바겐 버튼을 누르면 더 이상 외부 브라우저/새 탭으로 열리지 않습니다.
- 통합 프로그램의 폭스바겐 화면 안에서 바로 표시됩니다.
- 일반 회원 모드에서는 폭스바겐 회원 화면을 표시합니다.
- 운영진 로그인 상태에서는 폭스바겐 운영진 화면을 표시합니다.
- 기존 폭스바겐 자체 기능과 인증 방식은 그대로 유지합니다.

적용
- GitHub 파일만 교체하면 됩니다.
- Code.gs는 변경하지 않습니다.

참고
- 폭스바겐 Apps Script 쪽에서 iframe 표시를 차단하는 헤더가 설정되어 있으면 내부 표시가 막힐 수 있습니다.
  그 경우 폭스바겐 Apps Script 쪽 HTMLService 설정을 추가로 조정해야 합니다.
